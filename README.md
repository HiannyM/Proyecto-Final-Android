# 🍳 Cocina Fácil — Proyecto Final Integrador

Bienvenido al repositorio oficial de **Cocina Fácil**, una aplicación móvil desarrollada en Android con Jetpack Compose y Material 3.

## 📄 Documentación del Proyecto
* 📌 **[Ver Documento de Requerimientos y Diseño (REQUERIMIENTOS.md)](./REQUERIMIENTOS.md)**

## 🚀 Características Principales
* Catálogo interactivo de recetas.
* Checklist de ingredientes en tiempo real.
* Formulario reactivo para crear nuevas recetas.
